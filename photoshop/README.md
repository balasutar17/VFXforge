# VFX Forge Link for Photoshop

A Photoshop panel (Photoshop 2023 or newer) that sends what you paint
straight onto a layer in VFX Forge. See docs/photoshop-link.md.

- `vfxforge-link/` is the panel. CI zips it as `VFX-Forge-Link.ccx` in the
  latest release; double-click that to install it through Creative Cloud.
- To work on it, load the folder's `manifest.json` in Adobe's UXP Developer
  Tool (free from Creative Cloud) with Photoshop open.
